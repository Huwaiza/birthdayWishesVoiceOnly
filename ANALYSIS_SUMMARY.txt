BIRTHDAY VOICE GENERATOR — EXECUTIVE SUMMARY
================================================================================

PROJECT STATUS: Technically sound, but produces poor singing output

ROOT CAUSE: Bark is a speech synthesis model, not a singing model
  • Trained on billions of speech samples, not singing
  • [singing] tag provides hints but is unreliable
  • No pitch/melody guidance, so notes drift
  • No vibrato, legato, breath modeling
  → Result: Sounds like robot reciting lyrics in "sing-song" voice

FREE/OPEN-SOURCE ALTERNATIVES & EFFORT
================================================================================

OPTION                  QUALITY    EFFORT   LOCAL?   BEST FOR
────────────────────────────────────────────────────────────────────────
Current (Bark)          Poor        —        ✓       Baseline; online users only
Pitch-shift post-proc   Fair       2 hrs     ✓       Quick 20-30% improvement
Fish Audio S2           Fair-Good  2 hrs     Partial Better TTS with singing
RVC (voice conversion)  Good*      4 hrs     ✓       Polish if you have base vocal
GPT-SoVITS             Fair       6 hrs     ✓       Few-shot voice cloning
DiffSinger             Excellent  10-14d    ✓**     True singing (ARM64 buggy)
Suno API (cloud)       Excellent  2 hrs     ✗       Best quality, API required

* = RVC quality depends on source vocal quality
** = Apple Silicon support is buggy; expect 1-2 days debugging

COMPARISON:
  Suno > DiffSinger > RVC(good-source) > Fish S2 > Bark+PitchShift > Bark
